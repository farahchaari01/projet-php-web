# 🛍️ La Mode d'abord

A web-based **e-commerce application** developed with **PHP** to manage an online fashion store.

The application provides separate functionalities for **customers** and **administrators**, including product browsing, user management, order management, and category management.

## ✨ Features

### 👤 Customer

* User registration and authentication
* Browse products by category
* View product details
* Place orders
* Update profile information
* Send messages through the contact page
* Logout

### 🔐 Administrator

* Manage users (CRUD)
* Manage products (CRUD)
* Manage categories (CRUD)
* Manage customer orders
* Access an administration dashboard

## 🛠️ Technologies

* **PHP**
* **MySQL**
* **HTML5**
* **CSS3**
* **JavaScript**
* **Bootstrap**
* **jQuery**
